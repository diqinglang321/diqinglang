On a file page, use **Download raw file** to save it. To see the animations, open the PPTX in desktop Microsoft PowerPoint and start Slide Show. Click or press Space to advance each sequence. Slides do not advance automatically. There are 11 scenes, 30 native animation effects, one cohort Morph transition and embedded speaker notes. Actual PowerPoint playback has not been tested in this Linux environment.

The focus is randomisation and objective measurement, energy intake, ketosis verification, attrition and generalisability. The presenter will add their name and UID separately.

## Source
